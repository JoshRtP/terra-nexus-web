# First Refresh Content Package

This directory contains the content and page-level decisions required for the
first protected refresh of `terra.nexus`.

## Start here

1. `public-page-contract.md` — page hierarchy, routing, and content-level decisions.
2. `homepage-copy.md` — canonical homepage draft and selected messaging hierarchy.
3. `website-copy.md` — remaining landing, capability, audience-group, Case Studies, About, and Contact drafts.
4. `readiness-and-codex-handoff.md` — review gates and implementation boundaries.

`homepage-copy.md` supersedes the homepage section in the earlier combined
`website-copy.md` file.

The package defines 24 initial routes. It does not authorize production
publication or create standalone routes for Service Offerings, sub-offerings,
audience segments, or engagement models.
