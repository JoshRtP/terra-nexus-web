# Required Dimensions

| Dimension | Purpose |
|---|---|
| Service line | Connect proof to the client function and decision area. |
| Area of expertise | Connect proof to the market topic or call to action. |
| Audience segment | Identify the type of organization served. |
| Engagement model | Advise, Manage, or Operate. |
| Commodity / value chain | Identify the relevant crop, protein, ingredient, fuel, waste stream, or ecosystem. |
| Standard / methodology / program | Identify applicable certifications, registries, accounting systems, or market rules. |
| Geography | Identify the geographic scope. |
| Deliverables | Show the concrete work performed. |
| Outcome | Show the approved result without overstating causality. |
| Confidentiality | Control naming, disclosure, and reuse. |
| Approval status | Draft, approved, or retired. |

# Reuse Rule

A single engagement may produce multiple qualification modules when it covers distinct decisions, commodities, standards, or service lines. The modules must still identify that they derive from one client or engagement where relevant.
